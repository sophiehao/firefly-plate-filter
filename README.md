# Firefly Plate Filter

Paste any image (⌘V / Ctrl+V) and restyle it like a vintage insect specimen plate: olive-green wash, soft faded shadows, warm gold and pink highlights, fine grain on a pale paper ground.

Everything runs in the browser on a `<canvas>`, and nothing is uploaded anywhere.

## Controls

- **Presets:** Firefly, Moss, Dusk, Ember, Faded, Bold
- **Treatment levels:** overall strength, keep photo detail, detail sharpening, green tint, desaturation, iridescent highlights, pink accent, contrast, brightness, grain, sparkle
- **Colors:** shadows, midtones, highlights, accent, wash, paper, ring, label
- **Wash & fade:** wash strength, direction and start, plus a ghost fade and an overall fade
- **Background:** swap a flat background for the paper color
- **Plate annotations:** an optional specimen ring and label
- **Save PNG:** download the result

## Deploy

It's a single static `index.html` with no build step. On Vercel, import the repo and deploy with the default settings (Framework preset: **Other**).
